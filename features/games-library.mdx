The Nexxus games library is the heart of the platform — a curated archive of HTML5 and Flash titles you can browse, search, filter, sort, and launch directly in the browser without any installs or plugins.

## Game Data Model

Every title in the library is described by the `Game` interface, defined in `src/data/games.ts`:

```typescript
export interface Game {
  id: string;
  title: string;
  path: string;
  aliases: string[];
  categories: string[];
  type: "html5" | "flash";
  thumbnail?: string;
  featured?: boolean;
}
```

| Field | Description |
|---|---|
| `id` | Unique slug used for favorites and history storage |
| `title` | Display name shown on the card and in the player |
| `path` | Relative path used to build the iframe URL |
| `aliases` | Alternative names searched alongside the title |
| `categories` | Array of genre tags used for filtering |
| `type` | `"html5"` or `"flash"` — affects iframe URL format |
| `thumbnail` | Optional preview image; falls back to a monogram card |
| `featured` | Marks a title as a highlighted/hot pick |

### Sort Options

Use the sort dropdown in the filter bar to control ordering. The `SortOption` type supports four values:

| Value | Label | Behaviour |
|---|---|---|
| `popular` | Popular / Featured | Featured titles first, then favorites, then alphabetical (default) |
| `az` | Alphabetical (A – Z) | `localeCompare` ascending |
| `za` | Reverse (Z – A) | `localeCompare` descending |
| `recent` | Recently Played | Most recently launched first by timestamp |

## Search

The search bar (keyboard shortcut `/`) performs a **case-insensitive substring match** across three fields simultaneously:

- `game.title`
- `game.aliases[]` — every alternate name in the aliases array
- `game.categories[]` — allows searching by genre tag directly

If a game passes the search filter **and** the active category filter, it appears in results. The live counter in the top-right of the filter bar shows `filtered / total` titles.

<Note>
  Search and category filters stack — selecting "Puzzle & Logic" then typing "physics" will only return puzzle/logic/physics games whose title, alias, or category also matches the query.
</Note>

## Favorites

Star any game to add it to your favorites list. Favorites are persisted across sessions:

- **Storage key:** `nexxus_favorites`
- **Format:** JSON array of game ID strings, e.g. `["slope","retro-bowl","2048"]`
- Toggle the star button on any game card, in the list view, or in the active player to add/remove a title.
- The **Favorites Only** shortcut in the Navbar toggles the `favorites` category filter directly.

---

## Recently Played History

Each time you launch a game, Nexxus records a timestamp:

- **Storage key:** `nexxus_recent_history`
- **Format:** JSON object mapping game ID → Unix timestamp (ms), e.g. `{"slope": 1718000000000}`
- Select the **Recent** category filter to see your play history, sorted newest-first.
- Switching to the `recent` sort option within any other category also bubbles recently-played games to the top.

## Game Player

Clicking any game card opens the built-in game player — a full-width theater view with controls along the top bar.

### iframe URL Format

| Type | URL Pattern |
|---|---|
| HTML5 | `/games/{game.path}/` (trailing slash) |
| Flash | `/games/{game.path}` (no trailing slash) |

Flash game paths typically include query parameters, e.g. `flash/?game=slope-rider`, so the path is used verbatim without a trailing slash.

### Related Games

The bottom bar beneath the player automatically surfaces up to four **similar titles** — games that share at least one category tag with the active game. Clicking any suggestion swaps the iframe immediately.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `/` | Focus the search input (works from anywhere on the library page) |
| `Escape` | If a game is active → return to library; if search has text → clear the query |
| `Escape` (in intro) | Skip the cinematic intro sequence |

<Tip>
  The **random game** button (in the navbar and in the player's top bar) always picks from the **currently filtered list** — not the full catalog. Use this to your advantage: filter to a genre like "Puzzle & Logic" first, then hit Random to get a surprise puzzle game every time.
</Tip>
