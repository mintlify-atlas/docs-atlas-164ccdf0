The Nexxus AI Chat tab gives you a full-featured conversational AI assistant right inside the platform — no separate app or account required. It is powered by Google Gemini through the `@google/genai` SDK, with an automatic multi-model fallback chain to ensure high availability even when a specific model endpoint is unavailable.

## How It Works

All chat requests are routed through the Nexxus backend:

- **Endpoint:** `POST /api/chat`
- **Payload:** The last 10 messages of the conversation, plus the system instruction and the active API key.
- **Response:** JSON with `text` (the AI reply) and `model` (which model handled the request).

### Model Fallback Chain

When one model is unavailable or times out, the backend automatically tries the next in sequence:

1. `gemini-3-flash-preview`
2. `gemini-3.5-flash`
3. `gemini-3.5-flash-lite`
4. `gemini-3.6-flash`
5. `gemini-3.8-flash`

Each model attempt has a **25-second timeout** before the next fallback is tried. The model that ultimately responded is recorded in the `ChatMessage` object as `modelUsed`.

<Note>
  A valid `GEMINI_API_KEY` environment variable must be set on the server for the `/api/chat` endpoint to function. Without it, all requests will fail regardless of the client-side API key setting.
</Note>

## ChatMessage Type

Every message in the conversation — both yours and the AI's — is stored as a `ChatMessage` object:

```typescript
export interface ChatMessage {
  id: string;
  role: 'user' | 'model';
  content: string;
  timestamp: number;
  modelUsed?: string;
  isError?: boolean;
}
```

| Field | Description |
|---|---|
| `id` | Unique message identifier (e.g. `user-1718000000000`) |
| `role` | `"user"` for your messages, `"model"` for AI replies |
| `content` | Full message text — supports markdown formatting |
| `timestamp` | Unix timestamp in milliseconds |
| `modelUsed` | Which Gemini model generated this response (AI messages only) |
| `isError` | `true` if the message represents a connection or API failure |

## Persistence

Chat history is automatically saved to `localStorage` so your conversation survives page refreshes:

- **Storage key:** `nexxus_chat_history`
- **Format:** JSON array of `ChatMessage` objects
- Only the most recent **50 messages** are persisted to keep storage usage low.
- Click **New Chat** in the header to wipe the history and start fresh.

## API Key Management

<Tabs>
  <Tab title="Default Key">
    Nexxus ships with a default Gemini API key embedded in the app. It works out of the box — no setup required for most users.
  </Tab>
  <Tab title="Custom Key Override">
    If you have your own Google Gemini API key, you can override the default:

    <Steps>
      <Step title="Open API Settings">
        Click the **Settings (⚙)** button in the top-right of the chat header.
      </Step>
      <Step title="Paste your key">
        Enter your Gemini API key in the **Custom Key Override** field. Leave it blank to revert to the default.
      </Step>
      <Step title="Save">
        Click **Save**. Your key is stored in `localStorage` under `nexxus_gemini_key` and used for all future requests.
      </Step>
      <Step title="Reset">
        Click **Reset to Default** at any time to remove your custom key and return to the built-in default.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Warning>
  Your custom API key is stored in plain text in `localStorage`. Do not enter a key that has billing enabled on a shared or public device.
</Warning>
