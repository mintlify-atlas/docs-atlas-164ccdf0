Nexxus is a self-hosted web operating system and unblocked gaming platform built for environments where access to games and tools is restricted. Rendered entirely in a striking black-and-white monochrome aesthetic — pure `bg-black` canvas, `text-zinc-100` typography, crisp `border-zinc-800` dividers, and white-on-black selection highlights — it delivers a focused, distraction-free interface that feels more like a terminal dashboard than a typical game portal. This page covers the platform's architecture, its five major subsystems, key technical facts, and the keyboard shortcuts that power-users need to know.

## Architecture

Nexxus is a full-stack TypeScript application. The **backend** is an Express + Node.js server (`server.ts`) that handles game asset proxying, Gemini AI chat, and visitor telemetry. The **frontend** is a React 19 single-page application (SPA) written in TypeScript, bundled by **Vite 8** with the `@vitejs/plugin-react` plugin and styled using **Tailwind CSS v4**. In development, Express delegates all SPA requests to Vite's middleware. In production, Express serves the pre-built `dist/` folder as static files and falls back to `index.html` for client-side routing.

```
Browser ──► Express (server.ts :3000)
               │
               ├─ /api/chat          ──► Google Gemini AI (@google/genai)
               ├─ /api/telemetry/*   ──► In-memory session store → .cache/sessions.json
               ├─ /games/*           ──► Disk cache (.cache/games/) → GitLab upstream
               └─ /*                 ──► Vite dev middleware (dev) / dist/ (prod)
```

| Layer | Technology |
|---|---|
| Runtime | Node.js 18+ |
| Server framework | Express 4 |
| Frontend library | React 19 + TypeScript |
| Bundler | Vite 8 |
| Styling | Tailwind CSS v4 |
| AI SDK | `@google/genai` v2 |
| Icons | Lucide React |
| Animations | Motion (Framer Motion v12) |
| Build tool (server) | esbuild |

## Navigation Tabs

The top navigation bar exposes three primary tabs that switch the main content area without a full page reload:

- **Games** — the default view; browse, search, filter, and launch the full game library.
- **Schedule** — a class schedule tracker where users add periods with times, days, teacher names, and room numbers.
- **Chat** — the Nexxus AI Chat powered by Google Gemini, accessible with multiple AI personas.

## Key Technical Facts

- **Default port:** `3000`. Customize with the `PORT` environment variable.
- **Game asset cache:** `.cache/games/` — created automatically at server startup. Cached files are served with `Cache-Control: public, max-age=86400`.
- **Session persistence:** `.cache/sessions.json` — stores the last 500 visitor sessions across server restarts. Previous `online` sessions are automatically marked `closed` on startup.
- **Favorites & history:** Stored in the browser's `localStorage` under `nexxus_favorites` and `nexxus_recent_history`. They survive page refreshes but are scoped to the browser.
- **Intro sequence:** A cinematic fullscreen intro plays on the first visit of each browser session (`sessionStorage` flag `nexxus_intro_seen`). It does not repeat on subsequent tab navigations.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `/` | Focus the search bar (when not typing in an input) |
| `Escape` | Exit the active game and return to the library, or clear the current search query |
| `Shift+O` | Toggle the Visitor Telemetry / Admin Console overlay |
| `Escape` (during intro) | Skip the intro sequence immediately |
