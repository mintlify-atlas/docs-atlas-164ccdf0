Nexxus is a self-hosted web application that combines a curated arcade of 177+ unblocked HTML5 and Flash games with a Gemini-powered AI chat assistant, a live class schedule tracker, a community wallpaper engine, and a real-time visitor telemetry console. It runs on an Express + React stack and can be deployed anywhere Node.js is available.

<Steps>
  <Step title="Clone the repository">
    Clone Nexxus from GitHub and install dependencies with your preferred package manager.
  </Step>
  <Step title="Set your Gemini API key">
    Copy `.env.example` to `.env` and add your `GEMINI_API_KEY` from Google AI Studio.
  </Step>
  <Step title="Start the development server">
    Run `npm run dev` (or `bun run dev`) to launch the Express + Vite server on port 3000.
  </Step>
  <Step title="Open in your browser">
    Navigate to `http://localhost:3000` — the cinematic intro plays on first visit.
  </Step>
</Steps>
